Deltempo · Privacy Policy

Privacy Policy

Effective for all distribution channels: GitHub Releases (WPF) and Microsoft Store (WinUI). Last updated 2026-10-30.

Zero telemetry — 100% offline. Deltempo contains no telemetry, analytics libraries, advertising SDKs, crash reporting services, or background network beacons. Routine scanning, cleaning, memory optimization and uninstallation never touch the network. The single network feature is the optional update check, which contacts GitHub's public API over HTTPS, downloads nothing automatically, and sends nothing about you — only a request for the public release metadata of the project.

What the app writes on your machine

We list everything, because there is nothing to hide:

  • %LOCALAPPDATA%\Deltempo\logs\deltempo.log — rolling operation log (WPF head) and deltempo-winui.log (WinUI head).
  • %LOCALAPPDATA%\Deltempo\crash.log — an out-of-process crash note, written only when the shell itself crashes. It contains local file-system paths that appear in stack traces (for example your user profile path), and is readable by nothing outside this machine.
  • %LOCALAPPDATA%\Deltempo\journals\ — per-run cleanup journals, so every deletion can be reviewed.
  • %LOCALAPPDATA%\Deltempo\settings.json — your settings and preferences, stored locally.

Note on uninstalling: this data folder is not deleted when you uninstall Deltempo (the same is true of the GitHub build). If you want everything gone, delete %LOCALAPPDATA%\Deltempo\ after removing the app. Everything in it is plain, local files.

What the app does not do

  • No accounts, no sign-in requirements, no identifiers assigned to you.
  • No data leaves your machine through Deltempo. There is no upload path in the codebase.
  • No purchase, subscription, or advertising integration; the Store listing price is zero for the preview.

Microsoft Store distribution

When Deltempo is installed from the Microsoft Store, the Store platform itself processes the install, licensing and update metadata under Microsoft's own privacy statement. Deltempo adds nothing to that flow: it does not read Store identifiers, purchase states or device IDs for any purpose, and Microsoft's app signing/review requires no additional permissions from you.

Open source

Deltempo is MIT-licensed and its full source is public, so this policy is itself verifiable: see the repository and docs/THREAT_MODEL.md.
