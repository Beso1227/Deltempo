Formal 5-Tier Safety Classification

Every candidate path is categorized deterministically into one of five verified tiers:

PROTECTED (Score: 0)
Immutable

System32, WinSxS, bootmgr, user documents, SSH keys, cloud credentials, browser password databases, and active messaging session tokens.

SAFE (Score: 90–100)
Verified Disposable

DirectX/NVIDIA/AMD shader caches, Windows Delivery Optimization chunks, Windows Update downloads, and driver package leftovers.

LOW RISK (Score: 70–89)
Aged Leftovers

Downloaded standalone installers older than 48 hours located in standard temp and staging download directories.

REVIEW (Score: 30–69)
Review Required

Active temporary files modified within 24 hours or executables detected in non-standard temporary folders.

UNKNOWN (Score: < 30)
Preserved

Conservative default fallback: unclassified files are permanently preserved without modification.

Workflow

How Deltempo Works

Three simple steps give you complete confidence in what gets cleaned.

01

Scan

Deltempo scans selected scopes without touching anything on disk. It calculates candidates and identifies disposable cache structures.

02

Review

See exactly what was found by category and safety tier. Protected directories are locked out, and simulation mode lets you preview actions safely.

Clean

Applies the cleanup plan with pre-deletion revalidation. Files are either permanently unlinked or moved safely to the Recycle Bin.

Transparency

System Requirements & Limitations

Clear facts about what Deltempo requires, what it modifies, and its operational boundaries.

PLATFORM SUPPORT
64-bit Windows 10 & 11 Only

Deltempo is built for win-x64 architecture. Legacy 32-bit Windows and older releases (Windows 7/8.1) are not supported.

ADMIN ELEVATION
System Scopes Require UAC

User temp and caches clean without elevation. OS-level scopes (Windows Temp, Prefetch, Servicing logs) require running as Administrator.

FILE LOCKS
Active In-Use Files Preserved

Files with exclusive open handles held by active programs cannot be removed and are skipped gracefully without crashing.

MEMORY REALISM
Cache Recovery, Not Magic Hardware

Memory trimming flushes standby and working set pages to free pools; it does not expand physical RAM or guarantee higher frame rates.
