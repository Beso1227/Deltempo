Frequently Asked Questions

Will Deltempo log me out of my browser or desktop apps?

No. Deltempo specifically cleans disposable media and code caches (GPUCache, Code Cache, Cache_Data). It never touches authentication tokens, cookies, or configuration files.

Why does Deltempo require Administrator rights?

Windows protects system directories like C:\Windows\Temp, C:\Windows\Prefetch, and SoftwareDistribution\Download. Running as administrator allows Deltempo to safely purge these gigabyte-heavy system caches.

Is Deltempo completely free and open-source?

Yes, 100% free under the MIT License. There are no paywalls, no pro tiers, and zero tracking. The full source code is publicly inspectable on GitHub.
