Frequently Asked Questions

Will Deltempo log me out of my browser or desktop apps?

No. Deltempo specifically cleans disposable media and code caches (GPUCache, Code Cache, Cache_Data). It strictly never touches authentication tokens, cookies, passwords, or configuration files.

Why does Deltempo require Administrator privileges?

Windows protects system directories like C:\Windows\Temp, C:\Windows\Prefetch, and SoftwareDistribution\Download. Running as administrator allows Deltempo to safely purge these gigabyte-heavy system caches.

Is Deltempo completely free and open-source?

Yes, 100% free forever under the MIT License. There are zero paywalls, zero pro tiers, and zero background telemetry. The entire source code is publicly inspectable on GitHub.
