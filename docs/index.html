No! Deltempo is a 100% self-contained standalone executable. It includes its own bundled runtime and runs on any Windows 10/11 PC out-of-the-box.

Yes! The Auto-Pilot Guardian only targets 100% risk-free disposable caches and is protected by the automated 24-hour Safety Shield filter.
