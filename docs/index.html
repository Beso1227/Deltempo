Complete suite of Windows maintenance tools.

Organized cleanly into three functional pillars: Clean, Optimize, and Control.

CLEAN
  • Duplicate File Finder: 3-stage SHA-256 byte-level duplicate scanner with system path protection.
  • GPU Shader Caches: Purges DirectX, NVIDIA, AMD, and Intel shader caches safely.
  • Windows & User Temp: Cleans temporary directories past the 24-hour safety shield.
  • Delivery Optimization: Cleans peer-to-peer Windows Update cached chunks.
  • AppData Footprint Report: See exactly what is occupying AppData, largest first. Strictly read-only — there is no delete button, by design. Also detects data left behind by uninstalled Microsoft Store apps.
  • Developer Caches: Reclaims build directories from npm, pip, NuGet, and Cargo.
  • VSS Shadow Copy Pruner: Enumerate system restore points and prune obsolete snapshots safely.
  • Messaging App Scratch: Purges media caches for Discord, Telegram, and WhatsApp.
  • Browser Disk Caches: Cleans HTTP caches for Chromium and Firefox browsers.

OPTIMIZE
  • Squarified Treemap: Interactive hierarchical storage visualizer mapping space hogs instantly.
  • Standby List Purge: Reclaims standby memory pages via NtSetSystemInformation.
  • Working Set Trim: Trims private working sets across running applications.
  • System File Cache Reset: Flushes excessive file cache working sets safely.
  • Global Hotkey: Press Ctrl+Shift+M anywhere for instant 1-click memory flush.
  • OS Process Shield: Core processes (csrss, dwm, explorer) are shielded.
  • DISM & SFC Integration: One-click Windows Component Store health check and repair.

CONTROL
  • Deep Root App Uninstaller: BCU engine with silent batch removal and leftover file/registry sweeper.
  • Task Scheduler & Context Menu: Automated scheduled cleanups and 1-click Explorer right-click cleaning.
  • Low Disk Shield: Background tray guardian telemetry warning when free disk space is critical.
  • Startup AI Safety Verdicts: AI intelligence answering "Will anything go wrong if I disable this?".
  • Large File Hunter: Inspect large files with Recycle Bin undo protection.
  • Synchronous CLI: Native console executable for PowerShell and script pipelines.
  • CTT WinUtil Integration: 1-click link to the official Chris Titus Tech Windows Utility page — Deltempo never runs it for you.
  • Continuous Patch Delivery: Safe rolling updates with SHA-256 and PE header verification.
  • Multi-Language (in progress): Language selector for English, Arabic, Spanish, French, and German. The Cleaner workspace is localized and Arabic gets native RTL flow; modals and the remaining workspaces are not yet translated.
