How the number is made

Read, not tracked

This page asks GitHub for public release counters. It sets no cookie, loads no analytics and sends nothing about you to Deltempo. The request goes from your browser to GitHub.

One counter for both paths

Downloads from this website, from the README badges and from the GitHub Releases page all increment the same asset counters. There is no separate website tally to reconcile.

Refreshed while you watch

The tab re-checks every two minutes while it is visible. If GitHub rate-limits the request, the page falls back to the snapshot published with the site instead of showing an empty chart.
