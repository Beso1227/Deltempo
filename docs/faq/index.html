Frequently Asked Questions

Clear, technical, and honest answers about how Deltempo cleans and protects your system.

Deltempo is an open-source, portable Windows utility that safely cleans disposable cache files and flushes unreferenced memory. It is designed to replace aggressive or bloated PC cleaning tools with transparent, deterministic code.
No. Deltempo incorporates an immutable protection policy that strictly protects user personal directories (Documents, Desktop, Pictures, Videos, Music, code repos), browser saved passwords and cookies, and cloud/developer credentials (.ssh, AWS, GPG keys).
Any file modified within the last 24 hours in temporary directories is flagged as "Review Required" and excluded from automatic deletion. This ensures active installers, uncommitted documents, and currently running updates are never interrupted.
Deltempo utilizes native Windows NT kernel APIs (NtSetSystemInformation with memory list class 80 and EmptyWorkingSet) to flush standby list pages left behind by closed applications and trim idle process working sets. It does not terminate active programs.
Standard user profile cache cleaning runs without elevation. Cleaning system-level temporary files (e.g. Windows Update leftovers, Delivery Optimization) and flushing system memory standby lists requires Windows administrator privileges.
Zero telemetry. Deltempo contains no analytics SDKs, no tracking pixels, and no advertising beacons. Network activity only occurs if you explicitly request an update check against the public GitHub releases API.
