Deltempo Frequently Asked Questions

Everything you need to know about Deltempo's safety engine, NT kernel memory optimization, privacy architecture, and WinGet packaging.

Deltempo is an open-source, portable Windows utility that safely cleans disposable cache files and flushes unreferenced memory. It is designed to replace opaque PC cleaning tools with transparent, deterministic code.

Deltempo's protection policies are designed to exclude personal directories (Documents, Desktop, Pictures, Videos, Music, code repositories), browser saved passwords and cookies, and cloud/developer credentials (.ssh, AWS, GPG keys) from cleanup.

Files modified within the last 24 hours in temporary directories are flagged as "Review Required" and excluded from automatic deletion to avoid interrupting active installers, in-progress updates, or open work.

Deltempo utilizes native Windows NT kernel APIs (NtSetSystemInformation with memory list class 80 and EmptyWorkingSet) to flush standby list pages left behind by closed applications and trim idle process working sets. It does not terminate active programs.

Standard user profile cache cleaning runs without elevation. Cleaning system-level temporary files (e.g. Windows Update leftovers, Delivery Optimization) and flushing system memory standby lists requires Windows administrator privileges.

Deltempo contains no analytics SDKs, tracking pixels, or advertising beacons. Routine scan and clean operations run entirely offline. Network activity only occurs if you explicitly request an update check or download patch builds from GitHub.

Yes. Both Deltempo.exe and deltempo_cli.exe support command-line arguments. You can run deltempo clean temp --dry-run to simulate cleanups or deltempo status --json for automated monitoring.

Deltempo utilizes the native Win32 Restart Manager API (rstrtmgr.dll) to identify exactly which process holds an exclusive lock on a file. It performs up to 3 non-destructive retry passes with exponential backoff. If the file remains locked by an active process, Deltempo skips it safely rather than force-terminating running applications.

Deltempo provides 8 dedicated operational workspaces within a single portable binary: System Cleaner (26+ scopes), RAM Optimizer (NT kernel working set & standby flusher), Large File Explorer (deep disk hog discovery), Startup Manager (with multi-provider AI safety verdicts), Process Monitor (resource consumption tracker), System Repair (SFC/DISM health orchestration), Deep Root App Uninstaller (BCU engine with silent batch removal & leftover trace sweeper), and Terminal CLI (scriptable console automation).

No. Deltempo respects your system resources and personal choice. In the Deep Root App Uninstaller, restore point creation is an optional toggle that is turned off by default. If you prefer to have a system checkpoint before removing an application, simply check the box in the GUI or pass the --restore-point flag in the terminal CLI.

Deltempo combines the best aspects of all three while remaining 100% open source under MIT. Unlike CCleaner, it has zero telemetry and no paid upsells. Unlike BleachBit, it features a modern Fluent UI, native NT kernel memory optimization, and an app uninstaller. Unlike BCU, it includes an integrated 26+ scope disk cleaner, large file hunter, system repair tools, and a high-DPI tray monitor.

Deltempo uses a high-performance 3-stage duplicate detection pipeline: Stage 1 groups files by exact byte length, Stage 2 reads initial 4KB header prefixes to eliminate mismatches with minimal disk I/O, and Stage 3 computes full SHA-256 cryptographic hashes only when needed. Windows system directories and executable files are strictly immune from deletion.

The built-in Treemap Visualizer uses the squarified treemap layout algorithm (Bruls, Huizing, van Wijk) to display nested rectangles proportional to file and folder sizes. It operates 100% locally with zero external libraries and lets you instantly locate disk space hogs.

Every release is gated by 612 automated verification tests spanning unit tests, integration tests, timing benchmarks, and an adversarial filesystem security test suite (validating symlink traps, junction loop containment, and directory traversal immunity). All builds enforce a 0-warning compilation standard.
