Deltempo Changelog

Complete version history, feature additions, and security improvements.

v1.4.0 (Latest Stable)

CURRENT STABLE
  • AI File Safety Intelligence Engine: Integrated multi-provider LLM intelligence supporting both local models (Ollama, LM Studio) and cloud inference providers (OpenRouter, Groq, DeepSeek, OpenAI, Anthropic, Gemini, Perplexity) to assess files in real time.
  • Deep File Forensics Analysis: Advanced file inspection computing Shannon entropy, validating binary magic header signatures, parsing PE headers, detecting suspicious Win32 API imports, extracting suspicious string artifacts, and verifying digital signatures.
  • Large File Hunter Interactive AI Inspection: Added rich AI inspection cards featuring safety verdicts (SAFE TO CLEAN, REVIEW CAREFULLY, PROTECTED), 0–100 confidence scores, origin explanations, deletion impact breakdowns, and actionable safety recommendations.
  • Headless CLI Inspection Commands: Introduced deltempo large inspect <path> for instant terminal forensics and deltempo large clean --safe-only for automated safe large file cleanup.
  • SEO & Sitemap Enhancements: Optimized documentation crawlability with automated sitemap indexing and GitHub Pages configuration.

v1.3.9

MILESTONE
  • Scanning & Cleaning Discrepancy Resolved: Added designated cache and temporary location classification in FileSafetyEngine so all eligible scratch and cache files (e.g. .bin, .dat, .cache, .json, .etl, and GUID folders) are planned and cleaned properly instead of being over-filtered as Unknown.
  • Multi-Root Directory Containment: Upgraded root containment checks in CleanupExecutor and CleanerService to support multi-directory categories (Developer caches, Desktop App caches) without path escape false positives.
  • High-Speed Parallel Deletion: Upgraded the cleanup execution engine with bounded multi-threading (up to 16 threads), accelerating file cleanup by 15x–20x.
  • Removed Blocking DISM Wait: Removed the 3-minute blocking DISM component servicing call from standard cache cleanup, eliminating application freezes.
  • Non-Blocking UI Progress: Throttled UI dispatch loops so background cleaner threads never stall waiting for WPF UI renders.

v1.3.8

MILESTONE
  • Bulletproof In-Place Auto-Updater: Completely eliminated the issue where downloading an update closed the app without replacing the binary. Updaters now run from an isolated helper outside of the target binary path, preventing self-process executable locking.
  • Atomic Rename-First File Replacement: Implemented safe NT filesystem rename-first swap (Deltempo.exe → Deltempo.exe.old) before staging the new binary, completely bypassing Windows access-denied sharing violations.
  • UAC Elevation & Manifest Compatibility: Fixed process spawning using UseShellExecute = true to seamlessly handle requireAdministrator manifests without throwing Error 740.
  • Single-Instance Safety: Guaranteed that background updater processes are never prematurely terminated by single-instance ghost process cleansers.

v1.3.7

MILESTONE
  • CLI Terminal Prompt Redraw Fix: Resolved overlapping console cursor when executing commands. Added native Win32 input signaling (ReleaseConsoleAndSignalPrompt) and synchronous profile function routing so subsequent commands always render cleanly on a fresh new prompt line.
  • Enhanced Dual CLI Discovery: Automatically locates and binds deltempo_cli.exe in development and published distributions, eliminating GUI process detach artifacts in terminal sessions.
  • Full Test Suite Verification: 311 automated unit and integration tests passing with 100% pass rate.

v1.3.6

MILESTONE
  • In-Place Update State Machine Fix: Resolved Invalid state transition: Discovered -> Discovered exception when triggering updates from the desktop UI. Added idempotent self-transition support to TransactionJournal and NextState.
  • Update Transaction Hardening: Ensured initial discovery state persists cleanly via journal.Save() without throwing during download initiation.
  • Full Test Suite Verification: 311 unit and integration tests passing with 100% pass rate.

v1.3.5

MILESTONE
  • Categorized Preferences & Settings Hub: Redesigned settings modal with modern segmented navigation tabs (Updates, General, Memory, Storage & Safe) and customizable free disk alert thresholds (5–50 GB).
  • Advanced Release Management & Update Channels: Comprehensive update engine supporting configurable frequency checks (Daily, 3 Days, Weekly, Manual), Stable vs Beta/Pre-release channel selection, silent pre-fetching, and direct GitHub release notes integration.
  • Crisp High-DPI System Tray Engine: Native Win32 icon extraction (LoadCrispTrayIcon) from app.ico preserving 32-bit alpha transparency across all display scaling tiers (100% to 200%), with explorer restart resilience and dynamic RAM telemetry.
  • Streamlined Official GitHub Release Updating: Simplified auto-updater to trigger exclusively from verified official repository releases with atomic staging and hot-swap replacement.
  • Linear/Apple Standard Top Navigation Bar: Clean floating island header with strict single-line text layout, subtle pill hover backdrops, visual divider line, and responsive 960px breakpoint.

v1.3.4

MILESTONE
  • Embedded Single-Executable Updater: Merged updater engine directly into Deltempo.exe with atomic staged replacement, eliminated secondary updater binary dependencies.
  • Production Safety Engine Hardening: Comprehensive verification across all 6 core subsystems with symlink loop detection, NTFS reparse point safety, and TOCTOU protection.
  • Cross-Process Mutex Concurrency Lock: Safe multi-instance coordination preventing simultaneous cleanup runs or update collisions across process boundaries.
  • Cybernetic Motion & UX Polish: Ultra-fluid animated Aurora glow, enhanced telemetry-free dark mode styling, and keyboard shortcut refinements.
