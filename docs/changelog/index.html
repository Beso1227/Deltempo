Deltempo Changelog

Complete version history, feature additions, and security improvements.

v1.3.4 (Latest Milestone)

CURRENT STABLE
  • Embedded Single-Executable Updater: Merged updater engine directly into Deltempo.exe with atomic staged replacement, eliminated secondary updater binary dependencies.
  • Production Safety Engine Hardening: Comprehensive verification across all 6 core subsystems with symlink loop detection, NTFS reparse point safety, and TOCTOU protection.
  • Cross-Process Mutex Concurrency Lock: Safe multi-instance coordination preventing simultaneous cleanup runs or update collisions across process boundaries.
  • Cybernetic Motion & UX Polish: Ultra-fluid animated Aurora glow, enhanced telemetry-free dark mode styling, and keyboard shortcut refinements.
  • Comprehensive Test Suite: Reached 331 passing xUnit tests with 100% pass rate.

v1.3.3

MILESTONE
  • Continuous Patch Delivery System: Added support for rolling updates directly from main with SHA-256 and PE header verification.
  • Deterministic 5-Tier Safety Engine: Centralized immutable protection policy protecting OS core, developer credentials, and browser password databases.
  • Two-Phase Cleanup Architecture: Planning and simulation mode with pre-deletion revalidation immediately before file unlinking.
  • Native NT Memory Optimization: Working set reduction and standby list flushing via native NtSetSystemInformation calls.
  • Large File Hunter: Reversible large file cleanup with Windows Recycle Bin undo support.
  • Startup Process Manager: Protected core Windows security processes (Windows Defender, SmartScreen) from being disabled.
  • Automated Test Suite: Reached 266 passing xUnit tests with 100% pass rate.

v1.2.0

MILESTONE
  • 24-Hour Safety Shield: Automatic exclusion for actively modified files in temporary directories.
  • Messaging Apps Cache Scopes: Dedicated cleaning targets for WhatsApp, Telegram, Microsoft Teams, and Discord media scratch.
  • Native Terminal CLI: Headless execution flags (--dry-run, --silent, clean) for PowerShell and batch automation.
