Release History

Deltempo Changelog

Complete version history, feature additions, and security improvements.

v1.8.0 (Latest Stable)

CURRENT STABLE
  • Frosted Glass UI/UX Redesign: Elevated double-bezel visual hierarchy, ambient glow brand badge, unified title bar navigation island, 34pt tabular telemetry metrics, and tactile filter chip capsules.
  • Deep Multi-Drive Root Residual Sweep: Next-generation uninstaller residual scanner detecting leftover directories and registry remnants across all fixed drives (System, Data, ProgramData, AppData, AppData LocalLow).
  • Orphaned & Broken App Heuristics: Intelligent discovery of abandoned applications with missing uninstallers or invalid executable links, with 1-click purge and quarantine protection.
  • Windows RestartManager Zero-Reboot Engine: Native Win32 RestartManager API integration (RmStartSession, RmRegisterResources, RmShutdown) to gracefully shut down locking processes during deep cleans.
  • Enhanced Quarantine Vault: Safe transactional rollback system with instant ZIP archiving before leftover or orphan purging.
  • 640 Automated Tests: 100% test pass rate across all unit, integration, memory leak, and filesystem fuzzing suites with zero compiler warnings.

v1.7.5

PREVIOUS
  • Byte-Level Duplicate File Finder: High-performance 3-stage duplicate detection pipeline (exact size grouping → 4KB header prefix comparison → full cryptographic SHA-256 hash validation) with strict system directory immunity (DuplicateFileService).
  • Interactive Squarified Treemap Visualizer: Built-in storage bloat analyzer implementing the squarified treemap layout algorithm (Bruls, Huizing, van Wijk) for instant graphical drilldown with zero third-party dependencies.
  • Volume Shadow Copy & Restore Point Manager: Enumerate native VSS snapshots, create instant system checkpoints, and safely prune obsolete restore points by age threshold (VssService).
  • Task Scheduler & Explorer Context Menu: Automated recurring background cleanups via native Windows Task Scheduler and 1-click folder cleaning directly from the Windows File Explorer context menu (ScheduledTaskService, ShellContextMenuService).
  • Low Disk Shield & Tray Guardian: Proactive background tray telemetry alerts when free disk space falls below configurable safety thresholds (LowDiskShieldService).
  • Root Leftover Uninstaller Architecture: Integrated USN Change Journal scanning (UsnJournalScanner) and native Win32 directory walker (NativeFileScanner) alongside multi-drive root target detection (MultiDriveDetector) for sub-second residual leftover discovery.
  • Optional System Restore Points: Pre-uninstall restore point creation is an optional toggle (SystemRestorePointService), disabled by default to conserve disk and prevent unexpected system freezes. Supported via GUI checkbox and --restore-point CLI flag.
  • Quarantine Vault Backup: Automatic pre-purge compression and backup of program residual files into a recoverable ZIP archive in LocalAppData with 1-click restore (QuarantineManager).
  • Multilingual RTL Architecture: Complete localization for English, Arabic, Spanish, French, and German. Arabic activates true Right-to-Left (RTL) window flow while keeping metrics, paths, and counters in protected Left-to-Right layout.
  • Pro Eye-Comfort Themes: Re-engineered light theme (Porcelain Slate) and dark theme (Obsidian Titanium) with calibrated contrast, zero glare, and WCAG AAA compliance.
  • 5-Way Competitive Matrix: Comprehensive technical comparison against CCleaner, BleachBit, Bulk Crap Uninstaller, and Windows Storage Sense.
  • 612 Automated Verification Tests: Full test suite passing with 100% success rate across all unit, integration, memory leak, and adversarial security suites.

v1.7.0

PREVIOUS
  • Deep Root App Uninstaller: Complete uninstaller engine with deep residual leftover scanning (filesystem traces, registry keys, Start Menu shortcuts), broken uninstaller force wipe, and multi-provider AI application intelligence.
  • High-Visibility Expandable App Intelligence: Clear high-contrast description lines in the Apps tab with an interactive click-to-expand briefing card detailing application purpose, removal safety verdicts, install paths (with Explorer shortcut), and uninstall commands.
  • Startup Manager Intelligence & Impact Analysis: Comprehensive offline catalog and AI integration explicitly answering "Will anything go wrong if I disable this?", with clear safety badges (Safe to Disable, Caution / Sync, Essential / Keep) and consequence briefings.
  • Chris Titus WinUtil (CTT) Direct Integration: Embedded 1-click launcher for the official Chris Titus Tech Windows Utility directly from the Deltempo system tools workspace.
  • Process Manager Native Icon Extraction: Dynamic high-DPI Windows application icon extraction from running processes for instant visual identification.

v1.6.5

PREVIOUS
  • Integrated In-Window Workspaces: Replaced rigid popup windows and blackout backdrop overlays with fluid, edge-to-edge workspaces directly inside the main UI for Large Files, Startup Apps, Running Processes, Memory Optimizer, and System Repair.
  • Volume-Partitioned Concurrency: Partitioned scanning targets by physical drive root with per-volume concurrency throttling, eliminating disk queue contention across NVMe, SATA, and HDD storage.
  • Bounded Priority Heap Memory Capping: Implemented thread-safe TopFilesCollector min-heap bounded strictly to 30 items, running in $O(1)$ memory without allocating large object bags.
  • Real-Time Velocity & ETA Telemetry: Live throughput tracking displaying rolling files/s, MB/s, and projected completion ETA throttled to 250ms UI updates.
  • Win32 Restart Manager Integration: Integrated native rstrtmgr.dll to identify locking process names/PIDs during locked-file conflicts and schedule deferred boot-time cleanup.
  • Targeted Bottom-Up Directory Pruning: Replaced full recursive filesystem walks with ancestor-chain pruning for affected parent directories.
  • CLI Engine Overhaul: Fixed smart clean target filtering, resolved safe-mode shield discrepancies between scan and clean, and enabled context-aware package cache clearance while preserving 100% credential protection.
  • Comprehensive Test Verification: 501 automated tests passing with zero failures and zero warnings.

v1.6.1

PREVIOUS
  • Autonomous CLI Terminal Usability: Standalone CLI binary (deltempo_cli.exe) now ships with a dedicated asInvoker execution manifest, allowing all standard commands (status, scan, clean --safe, startup, large, register, help) to execute in any terminal without elevation blocking.
  • Production-Grade Safety Invariants: Sealed non-deletable risk tiers in CleanupPlanner; eliminated naive string matching in favor of canonical containment (PathSecurity.IsSubpathOf) preventing sibling directory prefix-collision attacks.
  • Two-Phase TOCTOU Protection: Implemented CleanupTransaction with pre-deletion size drift and reparse point rejection (CleanupErrorCategory) across all deletion pipelines.
  • Adversarial Filesystem Test Suite: Added 14 adversarial security tests validating symlink trapping, directory traversal prevention, and immunity against malicious external heuristics.
  • Native NT Memory Auditing & Benchmarks: Audited ntdll!NtSetSystemInformation calls with strict NTSTATUS return validation, automated token privilege revocation (RevertBoostPrivileges), and added reproducible memory benchmarks.
  • Comprehensive Documentation Suite: Added formal system architecture (docs/ARCHITECTURE.md), threat model & security boundaries (docs/THREAT_MODEL.md), testing guide (docs/TESTING.md), and release engineering handbook (docs/RELEASES.md).
  • Zero-Warning Release Build: 480 automated tests passing with zero skips, 100% clean formatting verification, and zero NuGet package vulnerabilities.

  • Drive Telemetry Resilience: Hardened system-drive telemetry to survive inaccessible or failing volumes without crashing.

  • CLI Usability & Safety: Added path validation for user-supplied scan targets, made process-kill resolution dynamic, and added an --exclude-system scope for large-file scans.
  • Tray Robustness: Wrapped all tray async menu handlers in exception guards so a single tray-action failure no longer crashes the process.
  • UI/UX Polish: Added empty-state guidance, inline scan-error cards with retry, keyboard shortcut badges, settings search/reset, skeleton loading states, and a log notification indicator.
  • Repository Hygiene: Removed duplicate site assets, legacy launcher scripts, local AI workspace artifacts, and stale root-level published binaries.
