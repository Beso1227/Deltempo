Deltempo Release Changelog

Complete update log of Deltempo Windows Cleaner: new cleaning scopes, performance optimizations, and NT memory enhancements.

v1.3.3 (Latest Stable)

Current Release
  • Messaging & Social App Cleaners: Added dedicated scopes for WhatsApp, Telegram, Microsoft Teams, and Discord media cache pruning.
  • Expanded Shader Cache Targets: Comprehensive coverage for NVIDIA DXCache/GLCache, AMD DxCache, and DirectX 12 pipeline registries.
  • NT Kernel Memory Engine: Integration of WinMemoryCleaner engine for safe standby list flushing and process working set trimming.
  • Large File Hunter: Fast recursive scanner identifying monolithic obsolete files exceeding user-configurable thresholds.
  • Multi-Language Support: Added localized UI for 5 languages (English, Arabic, Spanish, French, German).

v1.2.0

Previous Release
  • 24-Hour Safety Shield: Automatic exclusion for actively locked installer setups and recently modified temp files.
  • Recycle Bin Undo Safety: Cleaned files default to Windows Recycle Bin routing for instantaneous restoration.
  • Terminal CLI: Headless execution flags (--dry-run, --silent, --clean) for script automation.
