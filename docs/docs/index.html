Deltempo Technical Documentation

Complete reference manual covering Windows shader cache cleaner targets, user profile temp cleanup, and NT kernel memory architecture.

1. Windows Shader Cache Cleaner Architecture

Modern DirectX 11, DirectX 12, and Vulkan games pre-compile shaders to prevent stuttering. Over time, graphics driver updates and removed titles leave dozens of gigabytes of stale bytecode that never get purged automatically.

Targets Covered:

  • DirectX Shader Cache: %LOCALAPPDATA%\D3DSCache
  • NVIDIA Shader Cache: %LOCALAPPDATA%\NVIDIA\DXCache and %LOCALAPPDATA%\NVIDIA\GLCache
  • AMD Radeon Shader Cache: %LOCALAPPDATA%\AMD\DxCache
  • Vulkan Pipelines: Active and legacy Vulkan runtime cache registries

Safety Protocol: Deltempo's 24-Hour Safety Shield guards active pipeline files modified within the past 24 hours to ensure seamless gaming performance.

2. User Profile Cleaner Targets

Temporary files created during application extraction, crash reports, and user profile sessions often stay stranded permanently on disk.

Targets Covered:

  • User Temp: %USERPROFILE%\AppData\Local\Temp
  • Crash Dumps: %LOCALAPPDATA%\CrashDumps and Minidump directories
  • Package Installers: Staged MSI and setup bootstrap extractions
  • Messaging & Social Apps: WhatsApp, Telegram, Microsoft Teams, and Discord media caches

3. Windows NT Kernel Memory Optimization

Deltempo implements native NT kernel memory clean functions (powered by the WinMemoryCleaner engine):

  • Standby List Flush: Frees pages in system standby cache to eliminate micro-stutters under heavy workloads.
  • Working Sets Reduction: Safely trims memory working sets for background processes without terminating them.
  • System Working Set: Flushes kernel paged and non-paged buffers safely.

4. Terminal CLI Automation & Flags

Deltempo can be fully automated in CI/CD pipelines, scheduled tasks, and headless Windows setups:

# Analyze system clutter without deleting anything deltempo --dry-run # Clean user profile and GPU shader caches automatically deltempo --clean --shader-cache --user-temp --silent # Flush NT kernel standby memory and working sets deltempo --memory-boost
