Deltempo Architecture & Reference

Comprehensive reference guide covering the 25+ cleaning scopes, 5-tier safety classification, NT memory APIs, and command-line automation.

1. GPU Shader Cache Cleaning

Modern DirectX, Vulkan, and OpenGL games pre-compile shaders to reduce in-game compilation stalls. Graphics driver updates frequently leave obsolete bytecode caches on disk that are never reclaimed by standard Windows tools.

  • %LOCALAPPDATA%\D3DSCache — DirectX 11 & 12 unified shader bytecode
  • %LOCALAPPDATA%\NVIDIA\DXCache & GLCache — NVIDIA proprietary caches
  • %LOCALAPPDATA%\AMD\DxCache — AMD Radeon Adrenalin compiled shaders
  • %LOCALAPPDATA%\Intel\ShaderCache — Intel Arc & Iris Xe shader cache

Safety Mechanism: The recent file safety shield protects active shader pipelines written within the past 24 hours to prevent in-game recompilation hitches.

2. The 5-Tier Safety Classification Engine

Every discovered path is evaluated against protection policies, canonicalized to eliminate directory traversal, and classified into a deterministic safety tier before touching disk:

Tier 0: Protected (Score 0)
System32, SysWOW64, WinSxS, bootmgr, user personal folders (Documents, Desktop, Pictures), developer credentials (.ssh, AWS, GPG), browser login databases (passwords, cookies), and messaging authentication tokens. Never modified.
Tier 1: Safe (Score 90–100)
DirectX/GPU shaders, Delivery Optimization cached chunks, Windows Update downloads, driver installation leftovers, and crash dumps. Safe for routine cleanup.
Tier 2: Low Risk (Score 70–89)
Downloaded standalone installers older than 48 hours located in standard temp and staging download directories.
Tier 3: Review Required (Score 30–69)
Active temporary files modified within the past 24 hours or executables discovered in non-standard temp folders. Preserved in automated runs.
Tier 4: Unknown (Score < 30)
Conservative fallback for unclassified files: permanently preserved without modification.

3. Native Windows NT Kernel Memory Architecture

Deltempo interfaces directly with native NT kernel memory managers rather than forcing generic process termination:

  • Standby List Flush: Calls NtSetSystemInformation with SystemMemoryListInformation (class 80) to reclaim pages left in standby cache by terminated applications.
  • Working Set Trimming: Calls EmptyWorkingSet across running user processes using SeProfileSingleProcessPrivilege.
  • File Cache Reset: Calls SetSystemFileCacheSize to flush excessive filesystem working set pages.
  • Immunity Shield: System-critical processes (csrss, dwm, explorer, lsass, services, WindowsDefender) are protected from working set reduction.

4. Terminal CLI Automation Reference

Both Deltempo.exe and deltempo_cli.exe offer synchronous CLI execution with deterministic exit codes (0 = Success, 1 = Error, 2 = Update Available):

# 1. Run simulation scan without touching disk (dry-run)
> deltempo clean temp --dry-run
# 2. Execute verified live cleanup across temporary files
> deltempo clean temp
# 3. Output structured system memory and storage telemetry in JSON
> deltempo status --json
# 4. Check for official releases
> deltempo update check
# 5. Apply official release update safely
> deltempo update
